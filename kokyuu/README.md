# 一呼吸チェック

林業の作業の合間に、**いまの自分は「疲れている」のか「焦っている」のか**を数タップで認識するためのアプリです。
疲労と焦りは事故の大きな要因です。気づくだけでも行動が変わる、という考えで作っています。

## 使い方
1. 設問（疲れ3問・焦り3問）に「大丈夫／ちょっと／かなり」（0/1/2点）で答える
2. 疲労・焦りそれぞれ 0〜6点と、🟢OK／🟡注意／🔴危険、一言アドバイスが出る
3. 「30秒 一呼吸」で、吸う4秒・吐く6秒を3回
4. 推移タブで、10:00/12:00/14:00/16:00 の枠ごとの点数、7日間のグラフ、一覧を確認

判定ライン（初期値: 3点以上で注意、5点以上で危険）は設定画面で変更できます。
自己認識の目安であり、医学的な診断ではありません。

## 通知について
サーバーを使わないオフラインアプリのため、**アプリを閉じている間の時刻ぴったりの通知は確実には出せません**。
- アプリを開いている間: 設定時刻に通知・振動・画面バナー。過ぎてから開いた場合は未記録の枠を表示
- 確実に鳴らしたい場合: 設定画面の「カレンダー用(.ics)を保存」で、毎日繰り返しの予定としてスマホのカレンダーに登録

## データ
端末のブラウザ内(localStorage)に保存。CSV出力・JSONバックアップ/復元に対応。電波がなくても動作します。
ホーム画面に追加する手順は、親フォルダの README の「スマホでの使い方」と同じです。
