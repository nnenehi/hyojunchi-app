# 山受け 椪径級カウントアプリ

皆伐の山受けで、椪（はい）ごとに径級別の本数をカウントするスマホ向けアプリです。
標準地調査アプリ（親フォルダ）と同じ仕組み（1ファイルのPWA・端末内保存・オフライン動作）で作っています。

## 機能

- **現場**: 山林名・林班小班・担当者・日付を入力して現場を作成。複数の現場を保存して切り替えられます
- **椪**: 現場の中に、用途名（一般材・パルプなど）・材長（3.65m・2.4mなど）・樹種・椪No.・備考を持つ椪を作成。用途・材長・樹種はプリセットのチップから選ぶか自由入力。プリセットは追加でき、追加したものは長押しで削除できます
- **カウント**: 椪を選んで径級ボタン（10〜13cmは1cm刻み、14〜60cmは2cm刻み）をタップすると +1。タップごとに振動（触覚）と押し込みの表示で記録を確認できます。「−1」モードで減らす、「数値入力」モードで本数を直接入力（数え間違いの修正用）。60cm超は数値入力で追加。直前の操作は「取り消す」ボタンで戻せます
- **集計**: 椪ごとの本数と、径級×椪のクロス表を集計タブでリアルタイム表示
- **データ保持**: すべて端末内（ブラウザのlocalStorage）に自動保存。電波がなくても動作し、アプリを閉じてもデータは消えません
- **出力**: CSV出力（Excel対応・BOM付きUTF-8）3種類と、JSONバックアップ／復元

## CSVの形式

1. **現在の椪**: 先頭に現場・椪の情報、その下に「径級(cm),本数」の表。10〜60cmの全径級（10〜13cmは1cm刻み、14cm以上は2cm刻み）を0本も含めて出力するので、Excelの集計表にそのまま貼れます
2. **現在の現場の全椪**: 行＝径級、列＝椪のクロス表（椪No・用途・材長・樹種のヘッダ付き、合計行・合計列あり）
3. **全現場一覧**: 1行＝1椪1径級の縦長形式。複数現場のデータを溜めてExcelのピボットで集計する用

材積は計算しません（別のExcelで計算する前提）。

## スマホでの使い方

### 方法1: 無料ホスティングに置く（おすすめ・完全なオフラインアプリになります）

1. このフォルダのファイル一式（index.html / sw.js / manifest.json / アイコン画像）を
   [Netlify Drop](https://app.netlify.com/drop) にドラッグ＆ドロップするか、GitHub Pagesで公開する
2. 発行されたURLをスマホのChrome/Safariで一度開く
3. メニューから「ホーム画面に追加」を選ぶ
4. 以後は電波のない山でもホーム画面のアイコンから起動できます（サービスワーカーがキャッシュ）

標準地アプリと同じサイトに置く場合は、このフォルダ（`yamauke/`）ごと置いてください。
サービスワーカーの範囲とキャッシュ名が分かれているので、2つのアプリが同居しても互いに干渉しません。

### 方法2: ファイルを直接スマホに入れる

index.html をスマホに送って（メール・LINE等）ブラウザで開くだけでも動作します。
ただし機種によってはデータ保存が不安定な場合があるため、方法1を推奨します。

## 注意

- データは端末のブラウザ内にのみ保存されます。**ブラウザの「閲覧データ削除」でサイトデータを消すと記録も消えます**。作業後はCSVかJSONバックアップを出力してください
- iPhoneのSafariは、ホーム画面に追加していないサイトのデータを7日間使わないと消すことがあります。必ずホーム画面に追加して使ってください

## 動作確認（PC）

```
python -m http.server 8765 --directory hyojunchi-app
```

を実行し、ブラウザで http://localhost:8765/yamauke/ を開きます。
