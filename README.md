# 標準地調査 毎木記録アプリ

林業の分収地における標準地調査（毎木調査）で、2cm刻みの径級・樹種・伐倒区分を記録するスマホ向けアプリです。

## 機能

- **調査地情報**: 山林名・林班小班・地点を入力して標準地を作成。大面積施業地では地点ごとに複数の標準地を作成し、切り替えて記録できます
- **樹種**: トドマツ・カラマツ・スギ・エゾマツ・雑木 ＋ その他の樹種を自由に追加可能
- **記録**: 樹種と「残す／伐倒」を選んで径級ボタン（4〜60cm・2cm刻み）をタップするだけ。60cm超は数値入力。備考（二又・曲がり等）も付けられます
- **集計**: 樹種別の残存本数・伐採本数・間伐率（本数割合）を記録画面上部と集計タブでリアルタイム表示。径級別分布表も表示
- **修正**: 一覧タブで記録をタップすると径級・樹種・区分・備考の修正と削除が可能。記録画面には「直前の記録を取り消す」ボタンもあります
- **データ保持**: すべて端末内（ブラウザのlocalStorage）に自動保存。電波がなくても動作し、アプリを閉じてもデータは消えません
- **出力**: CSV出力（Excel対応・BOM付きUTF-8）、JSONバックアップ／復元

## スマホでの使い方

### 方法1: 無料ホスティングに置く（おすすめ・完全なオフラインアプリになります）

1. このフォルダの4ファイル（index.html / sw.js / manifest.json / icon.svg）を
   [Netlify Drop](https://app.netlify.com/drop) にドラッグ＆ドロップするか、GitHub Pagesで公開する
2. 発行されたURLをスマホのChrome/Safariで一度開く
3. メニューから「ホーム画面に追加」を選ぶ
4. 以後は電波のない山でもホーム画面のアイコンから起動できます（サービスワーカーがキャッシュ）

### 方法2: ファイルを直接スマホに入れる

index.html をスマホに送って（メール・LINE等）ブラウザで開くだけでも動作します。
ただし機種によってはデータ保存が不安定な場合があるため、方法1を推奨します。

## 注意

- データは端末のブラウザ内にのみ保存されます。**ブラウザの「閲覧データ削除」でサイトデータを消すと記録も消えます**。調査後はCSVかJSONバックアップを出力してください
- 間伐率は本数割合（伐採本数 ÷ 合計本数）です

## 動作確認（PC）

```
python -m http.server 8765 --directory hyojunchi-app
```

を実行し、ブラウザで http://localhost:8765 を開きます。
