## 0. 要旨（3分で読む要点）

1. **伐木は「木の安定を支える根を幹からはずす作業」であり、本質的に危険な作業である。** 倒れやすい方向に倒してよいとは限らず、可能な限り伐倒を「制御」する必要がある。その制御手段が受け口・追い口・ツルの3要素である。
2. **ツルは蝶つがい（回転軸）である**という認識は世界共通。回転軸はツルの中で最も力学的に弱く、圧縮応力と引張応力が釣り合う位置（会合線の後方）に形成され、追い口側の破壊に伴って会合線方向に前進する。ツル幅が不均一だと回転軸が傾き、伐倒方向がずれる。
3. **受け口を作る目的は「ツルを有効に働かせるため」**であり、受け口はツルが曲がるための空間である。受け口が塞がった瞬間にツルにかかる力は「曲げ」から「引っ張り」へ変わり、ツルは破断する。したがって**角度は大きいほど、深さは深いほどツルの機能が長く保持される**。
4. **受け口切りの不一致（下切り／斜め切りの切り過ぎ）は世界共通の禁止事項**。倒伏初期のツル破断、伐倒方向の制御不能、裂け上がり（Barber chair）、Stall（倒伏途中停止）の原因となる。
5. **追い口は受け口会合線より下に作ってはならない。** 実験（87本）では、追い口が会合線より低いと上向きクラック＝裂け上がりの破壊起点が生じた。会合線より2.5cm（1インチ）以上高いと上方向へは裂けにくい。低い追い口はツリーキックバック（元口の跳ね戻り）やヤリの原因にもなる。
6. **数値基準はあくまで「目安」であり、樹種・生育状況・地形・傾き等によって優先すべき事項は変わる。** 令和5年12月11日適用の林災防・災害防止規程改正で受け口角度は「45度を基本、少なくとも30度以上」となり、45度超の上限が実質的に外れた。
7. **今後の課題は「大径木伐採」と「木材伐出機械の安全」**。大径木は幹割れ・根張り・芯腐れ・枯れ枝のリスクが増す。機械災害は依然として多く、死亡災害は機械の転倒・転落と死角に起因する衝突に集中している。

## 2. 伐木作業の危険性と法令上の枠組み

### 2.1 伐木作業はなぜ危険か（スライド2）

伐木は「木の安定を支える根を幹からはずす作業」であり、**危険なのは当然（危険なはず）**という前提に立つ。危険要因として次が挙げられている。

- 質量が大きく、重心位置が高い
- 蔓や枯れ枝等、危険物の存在
- 不整地・急傾斜
- 気象条件（風向、雪）
- 木の状態が多様（樹種、腐れ、曲がり）

さらに、**倒れやすい方向に倒して良いとは限らない**（集材方向、支障木、退避路、材の価値などの制約がある）。したがって「可能な限り制御したい」「制御のための技術を学ぶ必要がある」という結論に至る。伐倒方向の判断には、樹冠の形・傾き・曲がり・風向・雪の付き方といった複数の要素が同時に関わる。

### 2.2 労働安全衛生規則 第477条（スライド3）

労働安全衛生規則（昭和47年労働省令第32号）第二編 安全基準 第八章「伐木作業等における危険の防止」第477条。**令和元年8月1日施行**。事業者は、立木を伐倒しようとする労働者に、立木ごとに次を行わせなければならない。

| 号 | 内容 | キーワード |
|---|---|---|
| 一 | 伐倒の際に**退避する場所**を、あらかじめ選定すること | 退避場所の選定 |
| 二 | **かん木、枝条、つる、浮石**等で、伐倒の際その他作業中に危険を生ずるおそれのあるものを取り除くこと | 危険の除去 |
| 三 | 伐倒しようとする立木の**胸高直径が20cm以上**であるときは、**伐根直径の1/4以上の深さの受け口**を作り、かつ、適当な深さの追い口を作ること。この場合において、技術的に困難である場合を除き、**受け口と追い口の間には、適当な幅の切り残し（＝ツル）を確保**すること |受け口1/4以上・切り残し確保 |

第2項により、伐倒しようとする労働者自身も前項各号に掲げる事項を行わなければならない。

### 2.3 林業・木材製造業労働災害防止規程の変更（スライド20）

- 令和5年9月12日 厚生労働大臣認可／**令和5年12月11日 適用**
- 受け口の下切り面と斜め切り面とのなす角度は、**45度を基本とし、少なくとも30度以上**とすること
- 受け口の下切りと斜め切りの終わりの部分を一致させ（この一致した線を「**会合線**」という）、かつ、**会合線は水平**とすること

**改正の意味**：45度を超える大きい角度の受け口も、数字の上では規程違反にならなくなった。受け口に関する解釈例規（昭和36年基発183号）には「30〜45度」という数字が残っており、変更の解説では45度の受け口角度に近づける旨が示されているが、条件によっては45度を超える大きい角度の受け口も積極的に採用できるようになれば安全性向上に寄与すると考えられる。なお、**角度の上限はオープンフェース受け口の90度と考えるのがよい**と整理されている。

## 4. ツル（弦）の力学

### 4.1 ツルは蝶つがい ― 世界共通の認識（スライド6・7）

- ツルを回転軸にして木は倒れていく。**蝶つがいがずれると伐倒方向もずれる。**
- したがって「**正しい回転軸を作成する ≒ 正しいツルを作成する**」。

ツルの役割は3つに整理される。

1. 木が倒れるときの**支点＆蝶つがい（回転軸）**
2. 伐倒**予定の軌道に導く**（ツル内部の回転軸／ツル全体の曲がり）
3. **軌道を保持する**

軌道を外す代表的な失敗として、①受け口が塞がりツルが切れて軌道を外れる、②ツルの片側が切れて軌道を外れる、の2つが図示されている。

### 4.2 回転軸はどこにできるか（スライド8・9/10）

- **回転軸となる中立軸は、ツルの最も力学的に弱い部分の、圧縮と引張応力のバランスがとれた場所にできる。**
- 倒れ始めると追い口側は縦に裂ける（長さは不明）。**ツルの追口側の破壊に伴い回転軸（中立軸）が移動する。**
- FEM解析（ANSYS）でも、力がかかっている箇所（暖色系表示。引張か圧縮かは問わない）はツル部に集中する。均質モデルではツルの中央に回転軸ができる。

### 4.3 回転軸は移動する（スライド12・13）

- ツルは追い口側から破壊が進み、**回転軸は会合線方向に前進する**。
- **重心の偏りがなく平行なツルなら伐倒方向への影響は無い**（＝前進しても方向はずれない）。
- 一方、角度を変えて前進する場合は方向がずれる。

**材質による違い（スライド13）**

| 樹種 | 挙動 |
|---|---|
| スギ | 回転軸が比較的中央寄りに形成される |
| ヒノキ | **追い口終端に近い位置に最初の回転軸ができる** |

いずれの場合も、**倒れる勢いのついたときの回転軸の向きが伐倒方向になる**。同じツル幅・同じ切り方でも樹種により挙動が変わるため、数値の一律適用には限界がある。

### 4.4 ツル幅の不均一（スライド11）

| 考え方 | 説明 | 傾向 |
|---|---|---|
| ツルの厚い方へ引かれる（ひねられる） | 予定方向からずれる | **日本の考え方に多い** |
| 受け口会合線の直角方向が伐倒方向となる | 会合線が方向を決める | **北欧の考え方に多い** |

結論：**ツルは厚い側の後ろ側から破壊が進む。ツル部分の材質によって違うが、伐倒方向はズレる可能性がある。**

### 4.5 ツル幅の目安の変遷（スライド14）

| 年 | 基準・出典 | 内容 |
|---|---|---|
| 1907年 | 吉野地方の例 | **スギ一割、ヒノキ七分** |
| 1984年 | 作業基準 | **直径の10%**が一応の目安 |
| 2017年 | 災害防止規程 | **伐根直径の1/10程度** |

数値が統一されにくい原因として、①直径の定義が複数ある（胸高直径・鋸断径・伐根直径）、②受け口や追い口の数値よりも後に決められた統一基準であり数値で示しにくい、の2点が挙げられている。

> **ツル幅はあくまで目安の数値。樹種や生育状況によって変える必要あり。**
> ツルの効きがわからないときは1/10残し、その後調整する。

## 5. 受け口

### 5.1 受け口とツルの関係（スライド15・16）

- 語源：受口の良否が良いことも悪いことも受け合う（請け合う）、さらに切り口が人の口によく似ているので「受合口」と言ったのが「受口」の語源となった（辻隆道）。
- **受け口が安全な伐倒に欠かせないと古くから分かっていた。**
- **受け口はツルが曲がれる空間**である。

> **受け口を作る目的は、ツルを有効に働かせるため。**

### 5.2 受け口角度の力学的な意味（スライド17）

- **受け口がふさがるとツルが壊れる（引き抜ける）。** このとき、ツルにかかる力は**曲げから引っ張りに変化**する。
- 釘抜きの模式図（力点・支点・作用点）で説明されており、受け口が塞がる前でも材質によってツルの後ろ側の破壊は進む。

> **受け口角度が大きいほど、ツルの機能が長く保持される可能性大。**

これが「角度は大きい方が安全側」という力学的根拠であり、後述の規程改正（45度基本・上限緩和）と整合する。

### 5.3 受け口角度 ― 日本の基準の変遷（スライド18）

| 年 | 主体 | 基準 |
|---|---|---|
| 1966年 | 林災防 | **30度以上** |
| 1992年 | 林野庁作業基準と林災防規程の整合性を重視 | **30度以上45度以下** |
| 2023年（令5.12.11適用） | 林災防 災害防止規程 | **45度を基本、少なくとも30度以上**（上限の記載なし） |

広葉樹の伐採が多い林野庁の作業基準では、**広葉樹では角度45度の受け口が安全**とされていた。

**なぜ昔は角度を小さくしたかったのか（材価の事情）**

- 昔は**元玉（一番玉）の価値が最も高かった**
  - 角度の大きい受け口は価値を損ねた
  - 根張り（根鉢）は元玉の証
  - 伐採点は極力下に（地面を掘ることもあった）
  - 格言「**梢一尺せめるより、元一寸下げろ**」
- 今は元玉の価値はそれほど高くない
  - 大きな角度の受け口も受け入れられる
  - 根張り部分は除去して出荷（製材機械の都合）
  - 伐採点も条件によっては高くて良い

つまり、**受け口角度を小さくしていたのは力学上の理由ではなく経済上の理由**であり、その前提が崩れた現在は、安全側（大きい角度）に振れる余地がある。

### 5.4 受け口角度 ― 諸外国の考え方（スライド19）

- 受け口角度**45度**とする技術書が大半
- **オープンフェース（70〜90度）**を推奨する動きも
- **45度以上大きくても安全上問題はない**
- ドイツの林業教科書『Der Forstwirt』でも大きな角度に変更された（図では約45〜60度、受け口深さ1/5〜1/3 ø、ツル幅1/10 ø）

### 5.5 受け口深さ（スライド21）

伐木造材作業基準 No.40（1969）より。

- **受口の深さ1/4は最低基準で、深い方が望ましい**
- チェーンソーは切削速度が速く**切り過ぎが恐い**（＝1/4という控えめな数値になった実務的理由）
- **ツル長さは木の幅（直径）が最も安全 → 受け口が浅いとツルが短くなる**
- **受口角度より受口の大きさや深さの方が重要**
- 受口は、樹種・樹形・地形・枝の張り具合・樹の傾き具合・伐倒方向などにより、作る位置、大きさ、角度などが異なる

> **（1/4という基準は）受け口が浅いことによる災害を減らすため。**

### 5.6 受け口切りの不一致（スライド22〜26）

英語では **Dutchman notch / Bypass notch**。

> **受け口切りの不一致は起こしてはならない（世界共通）。**

**不一致の2類型**

| 類型 | 内容 |
|---|---|
| 下切りの切り過ぎ | 下切り面が斜め切り面より奥まで入る（下切過長） |
| 斜め切りの切り過ぎ | 斜め切り面が下切り面より奥まで入る（斜切過長） |

**不一致が生じると何が起こるか（スライド23）**

- 倒伏初期にツルが壊れる
- 伐倒方向が制御できなくなる
- **裂け上がり（Barber chair）**が生じる
- 倒伏途中で止まってしまう **Stall** が生じる

なお、切過長が**3/8インチ（9.525mm）**を超えると生じる現象とする文献もあるが、未検証と注記されている。

**FEM解析結果**

| 解析条件 | 結果 |
|---|---|
| 斜め切りの切り過ぎ（スライド24） | **ツルの後側に大きな引張応力** |
| 下切りの切り過ぎ・追い口高さ＝受け口の2/3（スライド25） | 他より応力が低い → **Stall** |
| 下切りの切り過ぎ・追い口高さ＝会合線と同高（スライド25） | ツルの後ろ側に引張応力、**上方向へクラック → 裂け上がり** |

**メカニズムの整理（スライド26）**

切りすぎた部分がふさがる（閉じる）と、ツル後ろ側に大きな引張力がかかるため、**木が十分傾かない時にツルが破断する**。

| ケース | 現象 |
|---|---|
| 下切りの切り過ぎ | 切り過ぎ部分が塞がるとツルに引き抜く力が働き切れる → **ツルの早期破断** |
| 斜め切りの切り過ぎ | 同上 → **ツルの早期破断** |
| 下切りの切り過ぎ＋追い口が低い | 上に裂ける力も大きく働く → **ツルの早期破断＋裂け上がり** |

> **木は制御を失い自由に倒れる。**

## 6. 追い口

### 6.1 日本の追い口高さの基準の変遷（スライド28）

| 時期 | 基準 | 理由・背景 |
|---|---|---|
| 斧と鋸の時代 | 追い口高さは**受け口上辺近く**が良い（作業基準） | 元口の**切り直しの手間を省く**ため。上辺近くだと切り直しが少ない（サルカが小さい） |
| 1966年 | 災害防止規程：**受け口底面から3cm以上** | ― |
| 1992年 | 広葉樹と針葉樹を含めた基準として、受け口上端より**やや下方**という意味で**受け口高さの2/3**と定めた | 切り直しは多いが**力学的に優れている** |

### 6.2 北欧との考え方の相違（スライド30）

| | 北欧の考え方 | 日本の考え方 |
|---|---|---|
| 追い口高さ | **低い（会合線と同高）** | **高い（受け口高さの2/3）** |
| 狙い | **年輪の影響を最小限にして確実にツルを残す** | **元玉の品質優先**（切り直し量の抑制） |
| 説明 | 年輪に沿って裂けが生じ、予定のツル幅より狭くなる。追口高さが低いと年輪の影響は少なくなる | 引き残し(a)の裂けが軸から裂ける／引き追い(b)が根株から裂ける。引き残しによって辺材に力が偏り、引き裂かれた小片ができる（ヒルフ・ブラッツエル(1970)をトレース修正） |

すなわち、日本と北欧の差は「どちらが正しいか」ではなく、**何を優先するかの違い**として整理されている。

### 6.3 実験：追い口高さとクラックの方向（スライド32）

**供試木**：スギ61本、ヒノキ12本、カラマツ14本＝**計87本**を伐倒（胸高直径 平均26.0cm、最小14.5cm、最大36.3cm）
**記号**：A＝受け口下切り、B＝受け口斜め切り、C＝追い口高さ

| 追い口高さの条件 | 下方 | 上方 | 両方 | 計 |
|---|---:|---:|---:|---:|
| C＞B（会合線より高い） | 13 | 0 | 0 | 13 |
| B＞C≧2.5cm | 32 | 0 | 0 | 32 |
| 2.5cm＞C＞A | 14 | **3** | **1** | 18 |
| C＜A（会合線より低い） | 0 | **22** | **2** | 24 |
| **計** | **59** | **25** | **3** | **87** |

**得られた知見**

- 追い口高さが**2.5cm以上**だと**下向き**のクラックが生じる
- **2.5cm以下**だと**上向き**にクラックが生じることがある
- 受け口会合線（A）**より低いと上向き**にクラックが生じる
- **倒伏が始まるとすぐにクラックが入る**
- 受け口角度、樹種とは関係ない

### 6.4 クラック発生の解析結果（スライド33）

| クラック方向 | 評価 |
|---|---|
| 上方向 | **×** |
| 上下方向 | **△** |
| 下方向 | **〇** |

> **上方向のクラックは裂け上がりの破壊起点となる。**

### 6.5 裂け上がりによる被災（スライド34）

- 裂けた幹に激突される
- 裂けた幹でチェーンソーを押しつけられる
- **裂け上がった高さ分、後方まで元口が来る**（＝退避距離を裂上り高が上回る）
- 裂けた幹が落下して下敷きになる → **重篤な災害**につながる

> **裂け上がりにつながる要因を減らす。**

### 6.6 追い口高さと力のかかる範囲（スライド35）

追い口高さを0mm／+25mm／2/3／受け口上端と変化させた解析では、

> **追い口終端付近の力がかかる範囲は、追い口高さが上がると大きくなる。**

逆に言えば、**低い追い口は狭い範囲に応力が集中する**（＝局所破壊＝クラック・裂けの起点になりやすい）。

### 6.7 傾き木の追い口高さ（スライド36）

平成4年版『伐木造材業務従事者必携』（特別教育テキスト）より。

| 状況 | 追い口の位置 |
|---|---|
| **重心方向への伐倒** | 普通の位置より**高い位置** |
| **重心の反対方向への伐倒** | 普通の位置より**低い位置** |

### 6.8 追い口高さのまとめ（スライド37）

- **追い口は受け口会合線より下に作ってはいけない** ― 裂け上がりの原因となる
- 会合線より**2.5cm（1インチ）以上高い**追い口は上に裂けにくい ― 追い口高さの低いオープンフェースは注意が必要
- 低い追い口は力のかかる範囲が小さくなる

> **追い口高さは応力範囲や幹の裂けに影響する。**

### 6.9 ツリーキックバック（元口の跳ね戻り）（スライド38）

①受け口がふさがる → ②ツルが切れる → ③押し戻される → ④元が跳ねる、という4段階で発生する。

> **受け口角度が小さく、追い口高さが低い時に起こりやすい。**

## 7. 北欧式（オープンフェース）伐倒技術との比較

### 7.1 北欧式の特徴（スライド29）

1970年代後半、スウェーデンでオープンフェースの伐倒技術が確立された。

| 項目 | 内容 |
|---|---|
| 受け口角度 | **70〜90度**（大きい） |
| 追い口高さ | **低い（会合線と同じ高さ）** |
| 受け口深さ | **浅め**（木の直径の約1/5） |
| ツルの長さ | **木の直径の80%**（正円だと深さ1/5に相当） |

### 7.2 北欧式の問題点（スライド31）

- **日本では低い追い口は推奨されていない**
- 低い追い口は**幹の割れ**や**ヤリ**、**裂け上がり（Barber chair）**の原因と考えられている

### 7.3 日本方式と北欧方式の対照表（本報告書による整理）

| 項目 | 日本の標準 | 北欧（オープンフェース） | 力学的評価 |
|---|---|---|---|
| 受け口角度 | 45度基本（30度以上） | 70〜90度 | 大きいほどツル機能が長く保持される（北欧が有利） |
| 受け口深さ | 伐根直径の1/4以上（大径木1/3以上） | 直径の約1/5 | 深いほどツルが長くなり有利（日本が有利） |
| 追い口高さ | 受け口高さの2/3 | 会合線と同高 | 高いほど上方クラック・裂け上がりを抑制（日本が有利） |
| ツル長さ | ― | 直径の80% | 長いほど軌道保持効果が上がる |
| 優先事項 | 元玉の品質・裂け防止 | 年輪の影響排除・確実なツル確保 | ― |

日本方式と北欧方式は、**角度は北欧が力学的に優れ、追い口高さは日本が力学的に優れる**という「一長一短」の関係にある。この整理が、本講義の技術的な核心である。

## 8. 伐木の基本原則（スライド39〜42）

**前提：平坦地に直立している木の場合。伐倒する木の状況によって優先すべき事項は変わる。**

### 8.1 ツル（スライド40）

- **ツルは蝶つがい、正しい回転軸で予定の軌道に導く** ― ツルの最も弱い場所（会合線の後）に回転軸が形成される
- **倒伏時の軌道を保持する十分な強度と折れやすさ**
- ツル幅
  - ツル幅の不均一は伐倒方向がずれる一因
  - ツル幅は樹種や生育状況によって変える必要
- ツルの長さはなるべく長く ― 軌道を保持する効果が上がる（芯切りしても良い）
- 樹種の違いによるツルの効き具合は？ → **残念ながらわからない。10分の1残してみて現場で加減する。**

### 8.2 受け口（スライド41）

- 受け口を作る目的は**ツルを有効に働かせるため**
  - 受け口が塞がるまでツルは保持される可能性大
  - 世界的に見て角度を大きくする方へ変化
- 受け口深さは**深い方が望ましい**ことを承知した上で、チェーンソーによる切り過ぎを考慮して**1/4**に
  - 受け口深さが浅いことによるトラブルが多く報告
  - 受け口深さはツルの長さにも影響
- **受け口切りの不一致は起こしてはならない** ― ツルの早期破断を防ぐ

**数値まとめ**：角度＝基本45度／最低30度以上、深さ＝1/4以上（大径木1/3以上）、会合線は水平

### 8.3 追い口（高さ）（スライド42）

- 高めの広葉樹を含めて統一した結果、受け口上端よりやや下方という意味で**受け口高さの2/3程度**とした
- **会合線より下に作ってはならない**（実験・解析）
- 会合線より**1インチ以上上**が良い（実験）
- **低いほど応力が集中する**（解析）
- 低いと**ツリーキックバック**の原因に
- 低いと**ヤリ**がたちやすい（経験）
- 参考：ドイツでは追い口高さは径の1/10

## 9. これからの伐木の課題

### 9.1 大径木伐採の注意点（スライド45）

| 課題 | 具体的な影響 |
|---|---|
| 倒伏時の**幹割れ** | 伐倒方向が制限される |
| **根張りが大きい** | ツルの残し方が難しい／鋸断が困難に |
| **芯腐れ**が多くなる | 内部の状況判断が難しい |
| **太い枯れ枝**が増える | 上方への注意／確実な退避（ウィドゥメーカー） |

作業時間が長くなるため、伐倒作業中の状況変化にも注意が必要である。

### 9.2 Good side と Bad side（スライド46・47）

| Good side | Bad side |
|---|---|
| 重心と反対側 | 重心側 |
| 山側 | 谷側 |
| 風上 | 風下 |
| 足場が良い | 足場が悪い |
| 段差のない側 | 段差の際 |
| 無理なく作業できる側 | 無理な姿勢側 |

- Good side と Bad side を見極める
- **Bad side から作業を始め、Good side で終わり退避する**
- 作業時間の長い大径木は特に注意を払う必要
- **Danger zone（危険区域）とは別**の概念である点に注意

> **鋸断が進むに従いGood sideで作業できるよう計画を立てる。**

### 9.3 林業機械等による労働災害発生状況（スライド48）

厚生労働省 労働災害統計より（H27〜R6の推移）。伐木等機械（グラップル、プロセッサ、ハーベスタ、フェラーバンチャ）、走行集材機械（運材車、フォワーダ、トラクタ）、架線集材機械、機械集材装置・運材索道、簡易架線集材装置、その他の車両系林業機械、およびチェーンソー（×10表示）の死傷者数が示されている。

- **チェーンソーによる労災はまだ多い**
- R1.8.1 の**下肢の防護衣着用義務化も防げていない**

### 9.4 伐木等機械・走行集材機械による被災例（スライド54）

2019・2020年度死傷災害データ **146件**より。

| 類型 | 件数 | 事例 |
|---|---:|---|
| グラップル等の扱った材で**他者を被災させる** | **39件** | グラップルで4m材を動かしたら12m材の元にあたり、その先端部分が他の作業者の腰に激突 |
| 乗り降りの際など運転席や荷台からの**転倒・転落** | **20件** | クローラから飛び降りた際、地面に枝条があり不安定でバランスを崩し左足に体重がかかり被災 |
| **機械の転倒・転落** | **15件** | グラップルで伐倒したスギを集材中に材が滑り出し、重機が引っ張られ横転して転落 |
| **死角が原因**の被災 | **12件** | 後退時に死角に座っていた作業者に接触 |

> **死亡災害は機械の転倒・転落と、死角が原因の衝突に多い。**

### 9.5 機械の安定性（スライド49・50）

フェラーバンチャで立木を切り、つかんで旋回したらバランスを崩した、という事例から、**旋回すると安定性が変わる**ことを示している。

標準の油圧ショベルにおける安定性の比較数値（履帯の向き等による違い）：

| 姿勢 | 転倒支点と重心との距離 | 安定性の比較値 |
|---|---|---:|
| ① 履帯に対して横向き | 短い | **75%** |
| ② 履帯に対して斜め | 中間 | **100%** |
| ③ 履帯に対して前後方向 | 長い | **200%** |

同じ機械でも姿勢によって安定性は**約2.7倍（75%→200%）**の差が生じる。

### 9.6 ベースマシンの限界（スライド51・52）

- バケット容量0.5m³、12〜14tの機体の定格総荷重表では、**作業範囲最大では約1tしか持ち上がらない**（ただしバケット質量400kgの場合。グラップルだと**560kg**）
- アタッチメント質量の例：イワフジグラップル **840kg**、KETO150eco **825kg**

**機械を大きくすれば解決するか？**

- 現状の問題：長くて太い材を扱えない／太い立木を伐倒できない／エンジン馬力が足らない
- しかし大型化すると：**機械の輸送が高額に／路網の改修が必要**
- 結論：**可能ならより大きいベースマシンに**（ただしコストとのバランス）

### 9.7 オペレータからの視界（スライド53）

- **人との接触事故が多発している**
- **死角の範囲が大きい**
  - ブームが右側の視界を遮っている
  - エンジンルームが高くなってきている

> **運転手は死角域の確認後に動くこと。他の作業者は死角域への立ち入りを最小限に。**

### 9.8 安全作業の留意点（スライド55）

油圧ショベルをベースマシンとするものについて。

| 留意点 | 対応 |
|---|---|
| **能力を超えない** | 最大リーチは要注意 |
| **姿勢によって安定性が変化する** | 旋回姿勢に注意 |
| **長い物を扱う** | 危険範囲が大きい → 離れる |
| **作業機の回転と機体の旋回** | 特に慎重に |
| **視界が悪い** | 接近・近接作業に注意 |
| **機械の乗り降り** | 慎重に（「若いつもり？」） |

補助的対策として**目立つ服装**が挙げられている。

> **機械や自身の正しい能力や特性を知ること。**

## 11. 所見・考察

### 11.1 本講義の技術的意義

従来の伐木教育は「受け口1/4、追い口2/3、ツル1/10」という**数値の暗記**に留まりがちであった。本講義は、FEM解析（ANSYS）と87本の実伐倒実験という2つの手法で、これらの数値の**力学的裏付けと限界**を示している点に価値がある。特に、

- 受け口深さ1/4が「最低基準であって最適値ではない」こと（本来は深い方が良いが、チェーンソーの切り過ぎリスクを考慮した妥協値）
- 受け口角度が小さかったのは**力学ではなく材価（元玉の価値）の事情**であったこと
- 追い口高さ2/3が「広葉樹を含めた統一の結果」であり、切り直しの手間と力学的優位のトレードオフであったこと

といった「基準の成立事情」が明示されており、**基準を現場条件に応じて外す判断の根拠**が得られる構成になっている。

### 11.2 実務上とくに徹底すべき事項

力学的に「絶対に守るべきこと」と「調整可能なこと」を分けると次のようになる。

| 区分 | 事項 |
|---|---|
| **絶対に守る（例外なし）** | ①受け口切りの不一致を起こさない　②追い口を会合線より下に作らない　③会合線を水平にする　④ツル幅を均一にする |
| **条件により調整** | ①受け口角度（45度基本、条件が許せば大きく）　②受け口深さ（1/4以上、大径木は1/3以上、深いほど可）　③追い口高さ（2/3を基本、傾き木で上下調整）　④ツル幅（1/10を初期値として樹種・生育状況で加減） |
| **未解明・今後の課題** | ①樹種の違いによるツルの効き具合（現状「わからない」）　②切過長と裂け上がりの定量関係（3/8インチ説は未検証）　③追い口側の縦裂けの長さ |

### 11.3 制度改正の受け止め

令和5年12月11日適用の災害防止規程改正により、受け口角度は「45度を基本、少なくとも30度以上」となり、上限45度の制約が実質的に外れた。これは本講義が示す**「角度が大きいほどツルの機能が長く保持される」という力学的知見と整合する方向の改正**である。実務上は、
- まず45度を確実に作れるようにすること（現状30度台に留まる作業が少なくないと推察される）
- 条件が許せば45度超（上限はオープンフェースの90度と考える）も選択肢に入れること

の2段階で取り組むのが妥当と考える。

### 11.4 機械化に伴う新たな課題

チェーンソーによる労働災害は下肢防護衣の着用義務化（令和元年8月1日）後も減っていない。加えて、伐木等機械・走行集材機械では**扱った材で他者を被災させる事例が最多（146件中39件）**であり、これは伐倒技術そのものではなく**作業者間の位置関係と合図・立入管理**の問題である。技術教育（伐木のメカニズム）と作業管理（死角域・危険範囲の管理）は車の両輪として扱う必要がある。

## 12. 用語集

| 用語 | 意味 |
|---|---|
| **受け口** | 伐倒方向側に作るくさび形の切り込み。下切り面と斜め切り面からなる。ツルが曲がるための空間 |
| **会合線** | 受け口の下切りと斜め切りの終わりが一致した線。水平であることが求められる |
| **追い口** | 受け口の反対側から入れる水平の切り込み |
| **ツル（弦）** | 受け口と追い口の間に残す切り残し部分。伐倒時の蝶つがい（回転軸）となる |
| **回転軸（中立軸）** | ツル内部で圧縮応力と引張応力が釣り合う位置に形成される、実際の回転中心 |
| **伐根直径** | 伐倒後に残る切り株の直径。根張りを除いて測る |
| **裂け上がり（Barber chair）** | 幹が縦に裂けて跳ね上がる現象。重篤な災害につながる |
| **Stall** | 倒伏が途中で止まってしまう現象 |
| **ツリーキックバック** | 受け口がふさがりツルが切れて押し戻され、元口が跳ねる現象 |
| **ヤリ** | 伐根に槍状に残る鋭利な突起。低い追い口で生じやすい |
| **サルカ** | 元口に残る段差。追い口が低いと大きくなり、切り直しが増える |
| **ウィドゥメーカー** | 倒伏時に落下してくる枯れ枝等。直訳「未亡人製造機」 |
| **オープンフェース** | 北欧式の大きな受け口角度（70〜90度）による伐倒技術 |
| **Dutchman notch / Bypass notch** | 受け口切りの不一致（下切りと斜め切りが一致していない状態） |
| **Good side / Bad side** | 作業のしやすさ・安全性から見た木の周囲の区分。危険区域（Danger zone）とは別概念 |
| **元玉（一番玉）** | 幹の根元側の最初の丸太。かつては最も価値が高かった |
